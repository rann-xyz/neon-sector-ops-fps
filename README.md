## About

**Neon Sector Ops** is a single-player tactical first-person shooter built entirely in three.js, playable in desktop Chrome from static files with no build step and no network request. Two teams, short rounds, one ion carbine, and a HUD showing health, ammunition, round timer and score. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty — $1,000 in USDC.

## How to play

Open `game/index.html` in a desktop browser with WebGL 2, click to play, then use WASD to move, mouse to look, click to fire, R to reload.
